💜 FlashLearn – Flashcard Quiz App

A simple and interactive web application that helps students learn, revise, and test their knowledge using flashcards and timed quizzes.

📌 About the Project

FlashLearn is a web-based learning application developed using HTML, CSS, and JavaScript. Users can create flashcards, organize them by subject, mark difficult cards for revision, and take timed quizzes to test their understanding.

✨ Features

- Dashboard: Displays total flashcards, quizzes completed, average score, and best score.
- Flashcard Management: Add, edit, and delete flashcards.
- Subject-wise Filtering: Organize and view flashcards by subjects such as Java and DBMS.
- Difficult Card Revision: Mark difficult flashcards and revise them separately.
- Timed Quiz: Answer multiple-choice questions with a 20-second timer.
- Score Tracking: View quiz results and track your performance.
- Import and Export: Import and export flashcards using JSON files.
- Data Persistence: Saves flashcards and quiz statistics using browser Local Storage.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- JSON

▶️ How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your web browser.
4. Add flashcards and start learning!

No backend server or database installation is required.
